## Goal
A clean, fast dashboard that answers "how much did I train and what did I do" at a glance.

## Scope
1. `/` dashboard: range picker (last 4 / 12 / 52 weeks, custom), sport filter, KPI tiles from
   `/v1/stats/summary` (distance, moving time, elevation, count), weekly volume bar chart from
   `/v1/stats/weekly` (Recharts), totals-by-sport breakdown, "last synced" indicator.
2. `/activities`: table with date, name, sport, distance, moving time, pace/speed (derived per
   sport), elevation, avg HR; filters (`from`, `to`, `sport_type`) in the URL; "Load more" using
   `next_cursor` (keyset — never page numbers).
3. `/activities/[id]`: detail card from `/v1/activities/{id}`.
4. Formatting helpers (km, h:mm, min/km, km/h) with unit tests, metric units, Europe/Istanbul
   display time zone configurable via `NEXT_PUBLIC_TZ`.
5. Loading, empty and error states for every data block; responsive down to phone width;
   light/dark via `prefers-color-scheme`.

## Acceptance criteria
- [ ] Unit tests for formatting and pace/speed rules (running → min/km, cycling → km/h).
- [ ] Component tests for empty/error states and "Load more" appending without duplicates.
- [ ] Lighthouse-style basics: no layout shift on chart load, accessible labels on controls (axe check in a test).
