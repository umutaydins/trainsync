## Goal
The public surface, the runbook and the demo match the multi-user app.

## Scope
1. Caddy allowlist and `public_check` for `/v1/auth/*`; `X-Acting-User` stripped at the gateway.
2. `.env.example`, `.env.prod.example`: every new variable.
3. `docs/operations.md`: inviting users, resetting a password, deleting a user, capacity.
4. Demo: a demo user owns the seed; the demo stays read-only.
5. Backup counts include the new tables.

## Acceptance criteria
- [ ] prod-check: auth routes forwarded, `X-Acting-User` never reaches the API from outside.
- [ ] demo-check and restore-check-ci green.

## Verify
`make prod-check`, `make demo-check`, `make restore-check-ci`
