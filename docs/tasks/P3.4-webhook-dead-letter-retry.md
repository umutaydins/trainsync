## Goal
Failed events are retried with backoff and eventually parked, never lost silently.

## Scope
1. Cron `retry_failed_webhooks` every 5 minutes: select `status='failed' AND attempts < 8` whose
   next retry time has passed (`received_at`/last attempt + `min(2^attempts minutes, 6 h)`), enqueue
   `process_webhook_event` (job id includes attempt number).
2. Events with `attempts >= 8` stay `failed` (the dead letters) and are counted in sync status.
3. Also re-enqueue `pending` events older than 10 minutes that have no queued job (lost enqueue
   after a crash between insert and enqueue).
4. Use the `webhook_events (status, received_at)` index; batch size limit.

## Acceptance criteria
- [ ] A failing event is retried with growing delays and succeeds once fake_strava recovers (integration test with injected clock).
- [ ] After 8 attempts the event is no longer retried (test).
- [ ] A stale `pending` event without a job is recovered (test).
