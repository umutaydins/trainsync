## Goal
Recruiters can click a link and explore a realistic dashboard without ever seeing personal data.

## Scope
1. `compose.demo.yml` (separate project name, volumes, gateway on 127.0.0.1:8081) with
   fake_strava seeded, generated gym history, check-ins and nutrition logs (synthetic,
   deterministic). Phase 8 extends the seed with body measurements and proposals.
2. `DEMO_MODE=true`: every write endpoint returns 403 with a friendly message; the bot is off;
   the demo dashboard password is published in the README; nightly reset job.
3. README "Live demo" section with the Vercel link and demo credentials.

## Acceptance criteria
- [ ] Every mutating route returns 403 in demo mode (generated test over the OpenAPI spec).
- [ ] Demo seed contains no real data (seed is code; test asserts the source).

## Verify
```
make verify
```
