## Goal
The MacBook behaves like a small server: the stack comes back after reboot, and one script
controls everything.

## Scope
1. `scripts/mac-prod.sh up|down|status|logs [svc]|restart|doctor`.
2. `doctor` checks: Docker Desktop running and set to start at login, `pmset` sleep disabled on
   power (`sleep 0`, `disksleep 0`), enough disk, Tailscale up, Funnel config present, last backup age.
3. `deploy/macos/com.trainsync.stack.plist` LaunchAgent that waits for Docker and runs
   `docker compose -f compose.prod.yml up -d` at login; install/uninstall commands; logs to
   `~/Library/Logs/trainsync/`.
4. `docs/operations.md`: reboot test procedure, where logs are, how to update, how to stop.

## Acceptance criteria
- [ ] `shellcheck` clean; `doctor` reports each failure with a fix command (tests with mocked commands).
- [ ] Documented reboot test performed once and its output pasted into operations.md.
