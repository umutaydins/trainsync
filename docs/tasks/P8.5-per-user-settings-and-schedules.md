## Goal
Tone, language, check-in time, time zone, quiet hours, reminders and the sugar limit are each
user's own; timed messages follow each user's clock.

## Context
ADR 0036. Settings were global env values; `chat_settings` held language and profanity.

## Scope
1. `user_settings` row per user, created from the env defaults; `GET/PATCH /v1/me/settings`.
2. `/lang` and `/swear` write the linked user's settings.
3. Worker crons (check-in prompt and reminder, coach reminders) iterate users with a linked chat,
   in each user's time zone and quiet hours; notifications per `(user_id, kind, object_id)`.
4. Emergency number from the user's country (`EMERGENCY_NUMBERS`), default `EMERGENCY_NUMBER`.
5. Assistant: `ASSISTANT_DAILY_LIMIT` per user per local day, owner exempt.

## Acceptance criteria
- [ ] Two users in different time zones get their check-in prompt at their own local time.
- [ ] Quiet hours are each user's; nothing is sent inside them.
- [ ] The 51st question of a user's day is refused; the owner is not limited.
