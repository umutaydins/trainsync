## Goal
A user can take their data with them and delete their account (KVKK / GDPR).

## Context
ADR 0037.

## Scope
1. `GET /v1/me/export`: one JSON document with every row the user owns.
2. `DELETE /v1/me` (password): soft delete, sessions revoked, Telegram unlinked, `purge_user`
   enqueued; the purge deauthorizes Strava (best effort) and deletes the user's rows.
3. The owner account cannot be deleted.

## Acceptance criteria
- [ ] The export contains every table's rows of the user and none of another user's.
- [ ] After `DELETE /v1/me` the token is refused at once; after the purge no row of the user
      remains and fake Strava saw the deauthorize call.
