## Goal
One design system and one app shell that every page uses, in Turkish and English, on a phone first.

## Context
ADR 0039. The BFF and the per-user session are P8.7 (ADR 0034).

## Scope
1. `src/styles/tokens.css`: colour (dark-first + light), radius, spacing, type scale, shadows,
   motion durations; Geist Sans/Mono via `next/font`; theme cookie (`system|dark|light`).
2. `src/components/ui/`: button, card, input, label, select, switch, segmented control, tabs,
   dialog, responsive sheet (vaul drawer / dialog), dropdown menu, skeleton, badge, stat (big
   tabular number with count-up and ▲▼ change), progress ring, toast, empty / error states.
3. `src/i18n/`: next-intl request config (locale from the user's `lang`, cookie, Accept-Language),
   `messages/{en,tr}/<namespace>.json`; a key-parity test.
4. Shell: bottom tab bar (Today, Workout, Food, Progress, Me) under 768 px, sidebar above, safe
   areas, page transitions; owner-only Admin entry.
5. PWA: icons, a service worker caching the shell and an offline page (never API responses).
6. ESLint boundaries for `i18n/` and `styles/`.

## Acceptance criteria
- [ ] Every primitive has a unit test (role, keyboard, axe-clean render).
- [ ] No raw colour values outside `tokens.css`; both message languages have the same keys.
- [ ] At 360–430 px no page scrolls horizontally; touch targets are at least 44 px.
