## Goal
Programs can be changed by the user or by the engine at any time, and every change is visible,
explainable and reversible.

## Scope
1. `program_versions` (`program_id`, `version`, `snapshot` jsonb of days/exercises,
   `change_source` user/engine/llm, `reason`, `created_at`); current version pointer on `programs`.
2. Every program edit (P6 endpoints) goes through a service that writes a new version.
3. Structured diff between versions (exercise added/removed/swapped, sets/reps/rest/weight changed)
   as a typed list; `GET /v1/training/programs/{id}/versions`, `/diff?from=&to=`, `POST /revert`.
4. Workouts keep the version they were performed under (for honest progress attribution).

## Acceptance criteria
- [ ] Every edit path creates exactly one version (tests over all endpoints).
- [ ] Diff output matches fixtures for each change type; revert restores the snapshot (tests).
