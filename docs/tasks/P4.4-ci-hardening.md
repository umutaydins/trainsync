## Goal
CI is a trustworthy gate: coverage threshold, vulnerable-dependency check and a production-ready image.

## Scope
1. `pytest-cov`: coverage over `src/` with `fail_under = 85` (branch coverage); coverage XML as a CI artifact.
2. `make audit` running `uvx pip-audit` (or `uv pip` equivalent) against the locked deps; CI job.
3. Dockerfile: non-root (check), `HEALTHCHECK`, no dev deps in the runtime image, image size noted in README.
4. CI: cache uv, run unit + integration + fault + compose smoke + docker build, cancel superseded runs (`concurrency`).
5. Status badge in README.

## Acceptance criteria
- [ ] CI green on `main` with all jobs.
- [ ] Coverage ≥ 85% enforced (lowering the threshold to pass is not allowed).
- [ ] `make audit` passes or documents accepted findings.

## Verify
```
make verify
```
