## Goal
The gym screens work one-handed: big steppers, one-tap "set done", a full-screen rest timer.

## Context
ADR 0039; the existing Phase 6 training and nutrition pages keep their behaviour and tests.

## Scope
1. Workout: huge +/- steppers for weight and reps, one-tap set done with feedback, full-screen rest
   timer with a ring and vibration where supported, plate calculator in a bottom sheet, program
   builder and history restyled.
2. Food: today's log, add food in a bottom sheet, summary cards; Activities and Sync restyled;
   pull-to-refresh where it makes sense.
3. Every page multi-user aware: empty states for a user without Strava or data.

## Acceptance criteria
- [ ] Existing unit and e2e tests stay green; log a workout end to end on a 375 px viewport.

## Verify
`make web-verify`, `make web-e2e`
