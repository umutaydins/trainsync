## Goal
Each user connects their own Strava account; one big backfill never starves other athletes.

## Context
ADR 0037, ADR 0004 (two-priority budget), ADR 0015 (signed state).

## Scope
1. `/auth/strava/login` needs a user; the signed state carries the user id; the callback binds
   the athlete to that user; an athlete bound to someone else → 409; one athlete per user.
2. Webhooks: `owner_id` → athlete → user for every write.
3. Backfill stops after `BACKFILL_PAGES_PER_JOB` pages and re-enqueues itself.
4. `DELETE /v1/me/strava` disconnects (deauthorize + delete the athlete's data).
5. `docs/strava-setup.md`: athlete capacity increase.

## Acceptance criteria
- [ ] Two users connect two athletes; each only sees their own activities.
- [ ] A second user connecting an athlete bound to the first gets 409 and nothing changes.
- [ ] With one long backfill queued, another athlete's incremental sync still runs (test).

## Verify
`make verify`, `make test-fault`
