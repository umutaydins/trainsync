## Goal
A typed configuration layer, JSON logging and a FastAPI app factory with a liveness endpoint, so
every later task has a place to plug in.

## Context
- `CLAUDE.md` → Stack, Layout, Rules (settings via env, never log secrets).
- `docs/architecture.md` → §8 Operations.
- The repo already has tooling (`pyproject.toml`, `Makefile`, smoke test). Extend it.

## Scope
1. Add runtime dependencies with `uv add`: `fastapi`, `uvicorn[standard]`, `httpx`,
   `pydantic-settings`, `structlog`, `sqlalchemy[asyncio]`, `asyncpg`, `alembic`, `redis`, `arq`,
   `cryptography`, `prometheus-client`. Dev: `respx`, `testcontainers[postgres,redis]`,
   `asgi-lifespan` (or equivalent), `types-redis` only if mypy needs it.
2. Create the package layout from `CLAUDE.md` (`api/`, `strava/`, `sync/`, `db/`, `core/`) with
   `__init__.py` files and a `py.typed` marker.
3. `src/trainsync/core/settings.py` — `Settings(BaseSettings)` loaded from env / `.env`:
   | env var | type | default |
   |---|---|---|
   | `ENV` | `Literal["dev","test","prod"]` | `dev` |
   | `LOG_LEVEL` | str | `INFO` |
   | `DATABASE_URL` | str | `postgresql+asyncpg://trainsync:trainsync@localhost:5432/trainsync` |
   | `REDIS_URL` | str | `redis://localhost:6379/0` |
   | `STRAVA_API_BASE_URL` | str | `https://www.strava.com/api/v3` |
   | `STRAVA_OAUTH_BASE_URL` | str | `https://www.strava.com/oauth` |
   | `STRAVA_CLIENT_ID` | str | required |
   | `STRAVA_CLIENT_SECRET` | `SecretStr` | required |
   | `STRAVA_REDIRECT_URI` | str | `http://localhost:8000/auth/strava/callback` |
   | `STRAVA_WEBHOOK_VERIFY_TOKEN` | `SecretStr` | required |
   | `STRAVA_WEBHOOK_SUBSCRIPTION_ID` | `int \| None` | `None` |
   | `TOKEN_ENCRYPTION_KEY` | `SecretStr` (Fernet key) | required |
   | `STATE_SIGNING_KEY` | `SecretStr` | required |
   | `API_KEYS` | list of `SecretStr` from a comma-separated string | required |
   Expose `get_settings()` cached with `functools.lru_cache`; tests override via env or DI.
4. `.env.example` with every variable, safe dummy values and a comment on how to generate a Fernet
   key (`python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`).
5. `src/trainsync/core/logging.py` — structlog configured for JSON output (`ENV=prod`/`test`) or
   console (`dev`), ISO timestamps, log level from settings, contextvars merged (for `request_id`
   later). A processor that redacts values of keys matching
   `token|secret|authorization|password|api_key` (case-insensitive) to `"***"`.
6. `src/trainsync/entrypoints/api/app.py` — `create_app(settings: Settings | None = None) -> FastAPI` with a
   lifespan context (empty hooks for now, but structured so P1.2/P1.5 can add DB/Redis/httpx), and
   `GET /health/live` → `200 {"status": "ok"}`. Module-level `app = create_app()` must not crash at
   import time when env vars are missing — build it lazily (e.g. uvicorn `--factory`) and document
   the run command in `CLAUDE.md` → Commands if it changes.
7. A middleware that assigns a `request_id` (incoming `X-Request-ID` or uuid4), binds it to
   structlog contextvars and returns it in the response header.

## Out of scope
Database, Redis, Strava calls, `/health/ready` (P1.2).

## Acceptance criteria
- [ ] `uv sync --frozen` works from a clean checkout; `uv.lock` committed.
- [ ] Settings load from env; a missing required variable raises a clear validation error (test).
- [ ] `API_KEYS="a,b"` parses into two secrets (test).
- [ ] `repr(settings)` and log output never contain secret values (test with redaction processor).
- [ ] `GET /health/live` returns 200 and an `X-Request-ID` header; a provided `X-Request-ID` is echoed (test).
- [ ] mypy strict passes on `src/`.
