## Goal
A new user gets from an invite link to a configured account without help.

## Context
ADR 0034 (accounts, invites, owner reset links), ADR 0036 (Telegram linking), ADR 0039.

## Scope
1. Login; register with an invite code field (hidden when `REGISTRATION_MODE=open`, a closed
   notice when `closed`); `/invite/<code>` prefills it; logout; "forgot password" explains the
   owner-reset flow; `/reset/<token>` sets a new password.
2. Onboarding after the first sign-in: time zone, language, coach tone / intensity / profanity
   with a preview line, connect Strava (official "Connect with Strava" button, "Powered by
   Strava"), link Telegram (one-time code and bot link), nutrition profile; every step skippable.
3. `/privacy` and `/terms`: what is stored, Strava data use, deletion and export, contact.

## Acceptance criteria
- [ ] register → onboarding → dashboard works end to end (e2e).
- [ ] The Strava button and attribution follow Strava's brand guidelines (assets from Strava).

## Verify
`make web-verify`, `make web-e2e`
