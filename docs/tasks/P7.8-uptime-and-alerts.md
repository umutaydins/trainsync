## Goal
Know within 15 minutes when the Mac, Funnel or the stack is down — from outside the Mac.

## Scope
1. Scheduled GitHub Actions workflow (every 15 min): `GET /health/ready` on the public URL (and
   the demo URL); on failure (2 consecutive) send a Telegram message via the Bot API using repo
   secrets; recovery message when back. Avoid alert spam (state stored in the workflow cache or an issue).
2. Stack-internal alerts (from the worker): circuit open > 30 min, dead-letter webhooks > 0,
   backup older than 36 h, sync stale > 2 h → Telegram.

## Acceptance criteria
- [ ] Alert state machine unit-tested (down, still down, recovered, flapping).

## Verify
```
make verify
```
