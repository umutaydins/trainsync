## Goal
Every morning an iOS Shortcut sends the last days of Health samples (weight and body fat from the
Xiaomi S400 via Xiaomi Home, plus steps, resting HR, active energy) to trainsync without any
native app.

## Context
- Apple Health has no server API; HealthKit is on-device only. Shortcuts' "Find Health Samples"
  + "Get Contents of URL" can post JSON on a personal automation schedule.
- Xiaomi Home writes weight, body fat rate, height and body fat index to Apple Health once the
  user grants it in Settings → Health → Data Access & Devices → Xiaomi Home.

## Scope
1. Ingest token: `HEALTH_INGEST_TOKENS` (hashed at rest, comparable in constant time), sent as
   `Authorization: Bearer …`; scoped to `POST /v1/health/ingest` only (cannot read anything).
2. `POST /v1/health/ingest` accepts a forgiving JSON shape Shortcuts can produce:
   `{"samples":[{"type":"Weight","value":"78.4","unit":"kg","start":"2026-10-18T07:42:10+03:00","source":"Xiaomi Home"}, …]}`.
   Map Shortcut type names → kinds (Weight/Body Mass → weight, Body Fat Percentage → body_fat_pct
   (accept 0–1 or 0–100), Lean Body Mass, Height, Resting Heart Rate, Steps → daily steps,
   Active Energy → daily active kcal). Unknown types counted and ignored. Locale-tolerant numbers
   ("78,4"). Max 5,000 samples per request. Response: inserted / duplicate / ignored counts.
3. Daily aggregates table for steps and active energy (`date`, `kind`, `value`, `source`), upserted.
4. `docs/apple-health-shortcut.md`: exact steps with screenshots placeholders —
   (a) grant Xiaomi Home write access to Health; (b) build the Shortcut: one "Find Health Samples"
   per type (last 3 days), build dictionaries, "Get Contents of URL" POST with header;
   (c) Personal Automation → Time of Day 08:00 → Run Immediately; (d) how to test and read the
   response; (e) how to rotate the token. Include a copy-pasteable JSON example and a curl test.
5. Rate limit the endpoint (e.g. 60 requests/hour per token).
6. The guide uses the real public URL (`PUBLIC_API_BASE_URL`, Tailscale Funnel from Phase 7);
   add the ingest route to the `public-check` matrix (wrong token → 401 from outside).

## Acceptance criteria
- [ ] Payload sent twice → no duplicates; percentages in both scales normalised (tests).
- [ ] Token cannot call any other endpoint; wrong token → 401 (tests).
- [ ] Guide's curl example works against the compose stack (scripted test).
- [ ] A real Shortcut run from the iPhone reaches the production backend (owner check recorded in operations.md).
