## Goal
Stable public HTTPS URLs without a domain: `https://<mac>.<tailnet>.ts.net` for the real backend
(port 443) and `:8443` for the demo backend.

## Scope
1. `scripts/funnel.sh on|off|status` wrapping `tailscale funnel` / `tailscale serve` to forward
   443 → gateway 127.0.0.1:8080 and 8443 → demo gateway 127.0.0.1:8081 (Funnel allows 443, 8443, 10000).
2. `PUBLIC_API_BASE_URL` drives OAuth redirect URIs, webhook callback URL and CORS-free BFF config.
3. `make public-check URL=…`: from outside (GitHub Actions job) verify allowlisted routes work and
   blocked ones 404, TLS valid.
4. Document Funnel limits (beta, bandwidth limits) and the fallback (Cloudflare Tunnel with a domain).

## Acceptance criteria
- [ ] `public-check` passes against the real URL (manual run recorded in operations.md) and in a scheduled workflow.

make verify
