## Goal
Estimate real daily expenditure from what was eaten and how trend weight moved, and propose
target adjustments toward the goal — safely and in neutral language.

## Scope
1. Estimator (pure): over a window (default 21 days, minimum 14 with ≥ 80 % logged days),
   `TDEE ≈ mean_intake − (Δtrend_weight_kg × 7700) / days`; smoothed with the previous estimate;
   returns `insufficient_data` instead of guessing.
2. Target proposal (through the P8.5 proposal system, `kind=nutrition`): move target toward the
   goal rate; **hard guard rails** — never below BMR, deficit ≤ 25 % of TDEE, planned loss
   ≤ 0.75 % body weight per week, surplus ≤ 15 %, change per week ≤ 150 kcal; protein target
   suggestion 1.6–2.2 g/kg trend weight.
3. All texts neutral (no "bad", "cheat", body judgements) in every tone; a test scans them.
4. Expose estimate + inputs on `/v1/nutrition/tdee`.

## Acceptance criteria
- [ ] Estimator matches a fixture; returns insufficient_data on sparse logs (tests).
- [ ] Every guard rail enforced (table-driven tests).
- [ ] Neutral-language test passes for all nutrition texts.
