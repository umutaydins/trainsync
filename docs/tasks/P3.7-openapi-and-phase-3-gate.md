## Goal
`/docs` documents every endpoint with examples, and every Phase 3 criterion is proven.

## Scope
1. Add `summary`, `description`, response models, error responses (401/400/503) and
   `openapi_examples`/`json_schema_extra` examples to every route; tag groups (auth, webhooks,
   activities, stats, sync, health). A test asserts every operation in `app.openapi()` has a
   summary and at least one example for request/response bodies.
2. Export `docs/openapi.json` via a small script and a test that it is up to date.
3. `## Evidence` section in `docs/phases/phase-3-webhooks-api.md`.
4. Update `docs/diagrams.md` (webhook sequence, webhook event states) if the code diverged.
5. `README.md` → Status: tick Phase 3.

## Acceptance criteria
- [ ] Every Phase 3 criterion has evidence pointing to a test.
- [ ] OpenAPI completeness test passes; `docs/openapi.json` is current.
- [ ] `make verify` passes.

## Verify
```
make verify
```
