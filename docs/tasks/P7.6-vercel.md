## Goal
`https://trainsync-<name>.vercel.app` serves the dashboard and talks to the Mac backend through the BFF.

## Scope
1. `web/vercel.json` if needed; Root Directory `web`, pnpm, Node version pinned; `output:
   "standalone"` kept for Docker but harmless on Vercel.
2. Env per environment: Production → real backend (`TRAINSYNC_API_URL=https://<mac>.<tailnet>.ts.net`,
   real API key); Preview → demo backend (`:8443`) with the demo key. `DASHBOARD_PUBLIC_URL`
   per environment; CSRF/Origin checks accept the production domain and Vercel preview domains
   of this project only (pattern test).
3. Server-side fetch timeouts and a friendly "backend unreachable" page (Mac asleep/offline).
4. `docs/deploy-vercel.md`: connect GitHub repo, set env, protect previews (Vercel deployment
   protection), Hobby plan is for personal non-commercial use.

## Acceptance criteria
- [ ] Origin pattern tests; backend-unreachable page test.
- [ ] Production deployment logs in, shows real data; preview shows demo data (manual check recorded).

## Verify
```
make web-verify
```
