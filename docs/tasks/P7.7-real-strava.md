## Goal
Connect the real Strava account and receive real webhooks on the Mac.

## Scope
1. `docs/strava-setup.md`: create the API application (strava.com/settings/api), Authorization
   Callback Domain = the ts.net host, where to put client id/secret.
2. `scripts/strava-subscription.py create|view|delete`: Strava push subscription API
   (`POST/GET/DELETE https://www.strava.com/api/v3/push_subscriptions` with client credentials,
   `callback_url` = `https://<host>/webhooks/strava`, `verify_token`); stores the returned
   subscription id in `.env.prod` guidance.
3. First real connect → backfill; watch rate-limit usage on `/v1/sync/status`.

## Acceptance criteria
- [ ] Script tested against respx fakes for all three commands and error cases.
- [ ] Real connection performed and documented (manual, recorded in operations.md).

make verify
