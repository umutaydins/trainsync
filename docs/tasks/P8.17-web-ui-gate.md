## Goal
Prove the new web app end to end and leave screenshots for review.

## Scope
1. Playwright: register → onboarding → log a workout → logout → login; settings changes; progress
   period switching; another user's ids through the UI give the not-found page; admin hidden for
   users; axe checks on every page.
2. Lighthouse (mobile) performance and accessibility ≥ 90 on Today, Workout, Food, Progress.
3. Screenshots of every page at 375 and 1280 px, light and dark, into `~/trainsync-screens/`.

## Verify
`make web-verify`, `make web-e2e`, `make verify`
