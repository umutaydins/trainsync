## Goal
A user can connect a Strava account: the service redirects to Strava, handles the callback, stores
the athlete with encrypted tokens and enqueues the initial backfill.

## Context
- `docs/architecture.md` → §1 OAuth connect.
- Signed state (P1.3), `StravaClient.exchange_code` (P1.5), `TokenRepository` (P1.6).
- In docker compose the **browser** reaches fake_strava at `http://localhost:8001` while the
  **API container** reaches it at `http://fake-strava:8001`. So the authorize redirect and the
  server-side token exchange need different base URLs.

## Scope
1. Settings: add `STRAVA_OAUTH_PUBLIC_BASE_URL` (browser-facing, default = `STRAVA_OAUTH_BASE_URL`).
   Update `.env.example`.
2. `src/trainsync/modules/strava/router.py` router:
   - `GET /auth/strava/login` → `302` to
     `{STRAVA_OAUTH_PUBLIC_BASE_URL}/authorize?client_id=…&redirect_uri=…&response_type=code&approval_prompt=auto&scope=read,activity:read_all&state=<signed>`.
   - `GET /auth/strava/callback?code&state&scope` (also handles `error=access_denied`):
     verify state (400 on failure), require that granted `scope` contains `activity:read_all`
     (400 with a clear message otherwise), exchange the code, upsert `athletes` (by
     `strava_athlete_id`, set `active=true`) and tokens in **one transaction**, then enqueue
     `backfill` (arq job id `backfill:{athlete_id}` so a double callback doesn't enqueue twice).
     Respond `200 {"athlete_id": …, "strava_athlete_id": …, "backfill": "queued"}`.
3. `src/trainsync/modules/strava/repository.py` — `AthleteRepository.upsert_connected(...)`.
4. arq pool (`arq.create_pool`) created in the app lifespan and exposed as a dependency; an
   `enqueue_backfill(athlete_id)` helper in `src/trainsync/core/jobs.py` so tests can stub it.
5. Reconnecting an athlete that was deactivated sets `active=true` again and replaces tokens.

## Out of scope
The backfill job itself (P2.2) — enqueueing a job nobody consumes yet is fine.

## Acceptance criteria
- [ ] Login redirect contains all required query params and a state that `verify_state` accepts (test).
- [ ] Full flow against fake_strava (in-process) creates one athlete + encrypted tokens and enqueues exactly one backfill (integration test with Postgres + Redis).
- [ ] Calling the callback twice with the same athlete keeps one athlete row and one queued job (test).
- [ ] Bad/expired state → 400; missing `activity:read_all` scope → 400; `error=access_denied` → 400; nothing written (tests).
- [ ] The token exchange uses the internal base URL, the redirect uses the public one (test).
