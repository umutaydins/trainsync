## Goal
One place to see whether everything is moving in the right direction, and to approve what the
app suggests.

## Scope
1. `/progress`: weight (raw dots + trend line), body fat %, lean mass, goal lines and projected
   date; relative strength (e1RM / trend weight) for main lifts; weekly running km and gym volume
   side by side; steps and resting HR from Apple Health.
2. `/progress/goals`: create/edit goals, progress bars with projection.
3. `/training/programs/[id]/history`: version timeline with diffs and revert.
4. `/proposals`: inbox; each proposal shows reasons and a diff; approve all / select changes /
   reject with note; "explain" button when LLM is enabled.
5. `/settings/health`: ingest token create/rotate (shown once), link to the Shortcut guide,
   `export.zip` upload with progress (direct-to-API upload URL from P9.3).
6. Neutral copy on all body/nutrition views.

## Acceptance criteria
- [ ] Charts render API numbers (component tests); trend vs raw distinguishable without colour alone.
- [ ] Approve-subset flow results in the expected new version (e2e against compose).
- [ ] Upload flow works for a small generated export (e2e).
