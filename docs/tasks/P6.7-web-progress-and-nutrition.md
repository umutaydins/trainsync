## Goal
See whether you are getting stronger and how you eat, next to your running data.

## Scope
1. `/training/history`: workouts list (keyset), detail with sets, volume, duration, PRs.
2. `/training/progress`: per-exercise e1RM and best-set chart, weekly volume per muscle group
   (stacked bars), PR board; body-weight trend if entered.
3. `/nutrition`: today view — meals with entries, add food (search local + Open Food Facts,
   barcode entry field, favourites, recent), grams input with live kcal/macros; daily rings
   for kcal/protein/carbs/fat vs targets; weekly averages; energy balance card that clearly
   labels estimates and shows "unknown" when activity calories are missing.
4. Dashboard: add a "this week in the gym" tile (sessions, volume) and "today's intake" tile.
5. Neutral copy only on nutrition screens (no judgement words); profile/targets form with the
   below-BMR warning from the API shown as information, not blocking.

## Acceptance criteria
- [ ] Charts render API numbers exactly (component tests with fixtures).
- [ ] Add-food flow works with keyboard only; axe check passes.
- [ ] e2e (extend existing): generate program → start workout → log 3 sets with rest timer →
      finish → history shows volume; add two foods → today's kcal equals the sum.
