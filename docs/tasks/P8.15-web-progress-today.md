## Goal
The progress API (ADR 0038) becomes the screen users open to see how they are doing.

## Context
ADR 0038, ADR 0039.

## Scope
1. Progress: segmented period switcher (W / M / 3M / 6M / Y / All / custom), stat cards with big
   numbers and ▲▼ change, area/line charts (volume, weight with its moving average, kcal vs
   target), bars per sport and per muscle, e1RM per lift with PR markers, a year heatmap, the PR
   list. Touch tooltips, readable at 375 px, animated on period change.
2. Today: this week at a glance, today's planned workout, today's food, the latest activity, empty
   states for a fresh user without Strava.

## Acceptance criteria
- [ ] Switching the period updates every block (e2e).
- [ ] Empty, loading (skeleton) and error states for every block.

## Verify
`make web-verify`, `make web-e2e`
