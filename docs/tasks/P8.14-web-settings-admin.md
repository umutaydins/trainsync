## Goal
Users manage their own account; the owner manages invites and users without seeing their data.

## Context
ADR 0034, 0036, 0037, 0039.

## Scope
1. Settings ("Me"): profile (name, time zone, language), password, sessions (list / revoke),
   coach settings, digests, Telegram link / unlink, Strava connect / disconnect, data export
   download, account deletion with typed confirmation.
2. Admin (owner only): invites (create / list / revoke, copy link), users list (no data access),
   password reset link generation. Hidden from the shell and 404 for everyone else.

## Acceptance criteria
- [ ] Changing the language switches the UI language on the next render (e2e).
- [ ] A user never sees the Admin entry and gets the not-found page on `/admin` (e2e).

## Verify
`make web-verify`, `make web-e2e`
