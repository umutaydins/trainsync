## Goal
The weekly proposal arrives in Telegram and can be approved or rejected there.

## Scope
1. When a proposal is created, send a compact summary (reasons + changes) with inline buttons
   ✅ Approve · ✏️ Review on web · ❌ Reject; callbacks call the proposal API; stale buttons rejected.
2. Sunday summary: trend weight change, gym sessions/volume, running km, adherence, goal progress.
3. `/progress` command returns the same summary on demand.
4. Body/nutrition parts neutral in every tone; training parts follow the tone packs.

## Acceptance criteria
- [ ] Approve/reject via callback updates the proposal exactly once under duplicate delivery (test).
- [ ] Summary numbers equal the API (test); neutral-language test covers new texts.
