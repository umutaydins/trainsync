## Goal
Tables and pure functions for strength training that every later task builds on.

## Scope
1. Migration 0005 + models:
   - `exercises` (`id`, `slug` unique, `name`, `primary_muscle`, `secondary_muscles` text[],
     `equipment` enum-like string: barbell/dumbbell/machine/cable/bodyweight/kettlebell/band,
     `is_custom`, `created_at`). Seed ~60 common exercises (squat, bench, deadlift, OHP, row,
     pull-up, lunges, curls, …) via a data migration from `src/trainsync/modules/training/seed_exercises.json`.
   - `programs` (`id`, `name`, `goal` strength/hypertrophy/general, `days_per_week`, `weeks`,
     `active`, `created_at`); `program_days` (`program_id`, `day_index`, `name`);
     `program_exercises` (`program_day_id`, `exercise_id`, `position`, `sets`, `rep_min`,
     `rep_max`, `rest_seconds`, `start_weight_kg` nullable, `progression` string).
   - `workouts` (`id`, `program_day_id` nullable, `started_at`, `ended_at` nullable, `notes`,
     `strava_activity_id` nullable FK-free link).
   - `workout_sets` (`id`, `client_id` uuid unique, `workout_id` FK cascade, `exercise_id`,
     `set_index`, `reps`, `weight_kg` numeric(6,2), `rpe` nullable, `is_warmup`, `completed_at`,
     `rest_seconds` nullable = actual rest before this set).
   - `body_metrics` (`date` unique, `weight_kg`) — only what the user enters.
2. `src/trainsync/modules/training/math.py` (pure, typed, unit-tested):
   - set volume = reps × weight; workout/exercise volume excludes warm-ups;
   - e1RM (Epley) = `w × (1 + reps/30)` for reps ≤ 12, `None` above (unreliable), `w` for reps = 1;
   - PR detection: best weight per rep count, best e1RM, best session volume per exercise;
   - weekly volume per primary muscle (sets and kg).
3. Repositories for the new tables.

## Out of scope
HTTP endpoints (P6.2), program generation (P6.3).

## Acceptance criteria
- [ ] Migration up/down round trip; autogenerate shows no diff (integration).
- [ ] Math matches a hand-computed fixture (`tests/fixtures/training_math.json`), incl. warm-up exclusion and the reps > 12 rule.
- [ ] Seeded library loads; slugs unique (test).
