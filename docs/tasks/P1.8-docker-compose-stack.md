## Goal
`docker compose up` starts postgres, redis, fake-strava, api and worker; a scripted smoke test
proves the stack is healthy. CI runs it automatically once it exists.

## Context
- `docs/phases/phase-1-foundation.md` → task 2 and acceptance criteria.
- CI (`.github/workflows/ci.yml`) currently runs `make verify` only. This task adds a `docker`
  job (`docker build .`) and a `compose` job (`make compose-smoke`).

## Scope
1. `Dockerfile` — multi-stage with `uv`: builder (`ghcr.io/astral-sh/uv:python3.12-bookworm-slim`)
   runs `uv sync --frozen --no-dev`; runtime `python:3.12-slim-bookworm`, non-root user,
   `PYTHONUNBUFFERED=1`, default `CMD` runs the API with uvicorn (factory). Same image for worker
   and fake-strava with a different command. `.dockerignore` excludes `.venv`, `.git`, caches.
2. `src/trainsync/worker.py` — minimal arq `WorkerSettings` reading Redis from settings, with a
   `ping` job (arq refuses to start with no functions). P2.1 extends it.
3. `docker-compose.yml`:
   - `postgres:16-alpine`, `redis:7-alpine` with healthchecks and named volumes;
   - `fake-strava` on port 8001;
   - `migrate` one-shot service: `alembic upgrade head`, `depends_on` postgres healthy;
   - `api` on port 8000, `depends_on` migrate completed + redis healthy + fake-strava, healthcheck
     on `/health/ready`;
   - `worker` same image, `arq trainsync.worker.WorkerSettings`;
   - env: points Strava URLs at `http://fake-strava:8001`, `STRAVA_OAUTH_PUBLIC_BASE_URL` at
     `http://localhost:8001/oauth`, dummy secrets suitable only for local use (a fixed dev Fernet
     key generated once and committed **only** in compose, clearly labelled dev-only).
4. `scripts/compose_smoke.sh` + Makefile target `compose-smoke`:
   `docker compose up -d --build --wait` → assert `/health/ready` is 200 → run the OAuth flow with
   curl (`/auth/strava/login` → follow fake authorize redirect → callback) → assert via
   `docker compose exec postgres psql` that one athlete exists and `oauth_tokens.access_token_enc`
   is not the plaintext token → `docker compose down -v` (always, via `trap`). Non-zero exit on any failure.
5. Update `CLAUDE.md` → Commands and `README.md` → Run locally if commands changed.

## Out of scope
Real job logic in the worker (Phase 2).

## Acceptance criteria
- [ ] `docker build .` succeeds; image runs as non-root.
- [ ] `make compose-smoke` passes from a clean checkout on a GitHub-hosted Ubuntu runner (i.e. in your job) and cleans up after itself even on failure.
- [ ] `/health/ready` is 200 inside the stack; the smoke test proves an athlete with encrypted tokens was stored.
- [ ] `make verify` still passes.

## Verify
```
make verify
make compose-smoke
```
