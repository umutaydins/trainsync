## Goal
Prove every acceptance criterion in `docs/phases/phase-1-foundation.md` holds on `main`, close
any gaps, and mark Phase 1 done.

## Context
- `docs/phases/phase-1-foundation.md` (the criteria to prove).
- Tasks P1.1–P1.8 and their specs in `docs/tasks/`.

## Scope
1. Go through each phase-1 acceptance criterion and each task spec's criteria. For each, point to
   the test or command that proves it. If something is missing or only weakly tested, add or
   strengthen the test (small fixes are in scope; large missing features → split into a new task).
2. Specifically confirm the unit tests the phase doc names: backoff timing bounds,
   retryable vs non-retryable status codes, rate-limit header parsing, token refresh race.
3. Add `docs/phases/phase-1-foundation.md` → a `## Evidence` section: criterion → test/command.
4. `README.md` → Status: tick Phase 1.
5. Remove dead code, TODOs that are done, and make sure `CLAUDE.md` Commands are accurate.

## Out of scope
Anything from Phase 2.

## Acceptance criteria
- [ ] Every Phase 1 criterion has an entry in the Evidence section pointing at a real test or command.
- [ ] `make verify` and `make compose-smoke` pass.
- [ ] README Status shows Phase 1 checked.

## Verify
```
make verify
make compose-smoke
```
