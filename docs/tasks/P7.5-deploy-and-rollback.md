## Goal
Ship a new version to the Mac safely in one command, and go back just as fast.

## Scope
1. `make deploy`: require clean `main` equal to `origin/main` and green CI for that SHA
   (`gh run list`), build images tagged with the SHA, take a pre-deploy backup, run migrations as a
   one-shot container, `up -d` api/worker/bot, smoke test (`/health/ready`, a `/v1` call, bot `getMe`).
2. `make rollback`: previous SHA images back up; refuse if the failed deploy ran a non-reversible
   migration (migrations declare `reversible = True/False`) and print the restore procedure instead.
3. Deploy log in `~/Library/Logs/trainsync/deploys.log`; Telegram message on success/failure.
4. Decision recorded in an ADR: manual `make deploy` instead of a self-hosted GitHub runner on the
   personal Mac (security of running CI jobs on a personal machine).

## Acceptance criteria
- [ ] Deploy script tested with mocked docker/gh; smoke failure triggers automatic rollback (test).

## Verify

make verify
