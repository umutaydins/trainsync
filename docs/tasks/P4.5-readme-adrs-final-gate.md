## Goal
The repository explains itself to a reviewer in five minutes, and every Phase 4 criterion is met.

## Scope
1. README: what it is and why, architecture diagram (link/embed from `docs/diagrams.md`),
   failure-modes table (or link), how to run, API examples (`curl`), load-test results, design
   decisions with links to every ADR, status (all phases ticked).
2. Review `docs/decisions/`: at least 4 ADRs (expected ≥ 8 by now), consistent format, accurate
   to the final code.
3. `docs/diagrams.md`: regenerate the class diagram from the real code and check every
   sequence/state diagram against the implementation.
4. `## Evidence` section in `docs/phases/phase-4-reliability-ci.md`.

## Acceptance criteria
- [ ] CI green on `main`.
- [ ] README has real numbers and no TODO/placeholder text.
- [ ] ≥ 4 ADRs, all linked from the README.
- [ ] Diagrams match the code.
